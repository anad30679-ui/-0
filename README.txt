آفاق الذكاء الاصطناعي — نسخة 3D
=================================

الملفات:
- index.html : الصفحة الرئيسية والأقسام.
- style.css  : تصميم 3D، الحركة، الألوان، الوضع الليلي والنهاري والتجاوب.
- script.js  : محتوى الأقسام، تلميحات المصطلحات، نجوم الخلفية، والتفاعلات.

التشغيل:
1. فك ضغط ملف ZIP.
2. افتح المجلد في VS Code.
3. افتح index.html في المتصفح، أو شغّله باستخدام Live Server.
4. الخط Cairo يتم تحميله من Google Fonts؛ عند عدم وجود إنترنت سيستخدم المتصفح خطًا بديلًا.

المميزات:
- كرة ذكاء اصطناعي ثلاثية الأبعاد بتأثيرات CSS.
- خلفية نجوم متحركة مرسومة على Canvas.
- بطاقات بزاوية 3D تتفاعل مع حركة الماوس.
- ثلاثة أقسام: المقدمة، الفوائد العشر، والأضرار الثمانية.
- تلميحات للمصطلحات، وضع ليلي/نهاري، وزر إيقاف الحركة.
- تصميم متجاوب مع الشاشات الصغيرة.
